# rindfall-site

Trang giới thiệu, chính sách riêng tư và hỗ trợ của game iOS **Rindfall** (repo game: nguyenvanlamm/rindfall).
GitHub Pages phục vụ thẳng từ nhánh `main` (không có workflow): https://nguyenvanlamm.github.io/rindfall-site/

- `index.html`: trang giới thiệu (tiếng Anh)
- `privacy.html`: Privacy Policy URL cho App Store Connect
- `support.html`: Support URL cho App Store Connect
- `assets/`: icon (`assets/logo/icon_1024.png` của repo game), ảnh chụp từ `tool/screenshot_main.dart`, ảnh chia sẻ
  1200x630, font Cormorant Garamond (OFL, `assets/fonts/cormorant_garamond_ofl.txt`)
- `robots.txt`, `sitemap.xml`, `llms.txt`: cho máy tìm kiếm và bot AI (robots.txt thật nằm ở gốc host, repo
  `nguyenvanlamm.github.io`; bản ở đây ghi lại chính sách)
- `index.html.md`, `privacy.html.md`, `support.html.md`: bản Markdown của từng trang cho bot AI; sửa trang HTML thì
  sửa luôn bản `.md`
